## Numbered Findings List

### Tier 1: Hard Gate (Priority: HIGH)

1. **R-02 (Copywriting) [HIGH]**
   - *Reason:* Em dashes (`—`) are used in UI text as fallback placeholders in `Settings.tsx` (line 288), `Queue.tsx` (lines 327, 335, 345), and `Library.tsx` (line 476).
   - *Remediation:* Replace all UI em dashes with clean hyphens (`-`), empty values, or descriptive labels (`None`).

2. **R-32 (Keyboard Accessibility) [HIGH]**
   - *Reason:* Modals (`AddLibraryModal`, `EditLibraryModal`, `DirectoryBrowserModal`, `SimulatorModal`) lack `Escape` key listeners to dismiss, and `:focus-visible` outline rings are missing across interactive buttons and links.
   - *Remediation:* Add global `Escape` key event handlers to all modal overlays and declare visible 2px keyboard focus outlines in `styles.css`.

3. **R-25 (Color Contrast) [HIGH]**
   - *Reason:* Secondary text color (`--text-dim: #64748b`) against card backgrounds (`#151d30`) achieves ~3.2:1 contrast, failing WCAG AA (4.5:1 required for normal body text).
   - *Remediation:* Adjust subdued text tokens to `#8494ab` or lighter to guarantee WCAG AA compliance across all labels and paths.

4. **R-27 (UI States) [HIGH]**
   - *Reason:* Empty and filtered states in `Queue.tsx` and `Library.tsx` present bare, unhelpful table cells ("No transcode jobs in this view") lacking context or call-to-action.
   - *Remediation:* Provide contextual empty state components explaining why the view is empty with a direct next step.

5. **R-37 (Design Direction Required) [HIGH]**
   - *Reason:* Project lacked a formal `DESIGN.md` defining brand personality, target audience, color tokens, and antislop dials.
   - *Remediation:* Adopt the proposed `DESIGN.md` (dial ENERGY 2 / RHYTHM 2 / MOTION 1, homelab engineering character).

---

### Tier 2: Purpose-Gate (Priority: MEDIUM)

6. **R-04 (Icons & Emoji Decoration) [MEDIUM]**
   - *Reason:* Literal emojis are scattered over 60+ locations across navigation (`📊`, `🎬`, `⏳`, `⚡`, `⚙️`), action buttons (`➕`, `▶️`, `⏸️`, `🧹`), headers, and badges.
   - *Remediation:* Remove decorative emojis and introduce clean, lightweight inline SVG icons tailored to media library workflows.

7. **R-01 (Color & Gradients) [MEDIUM]**
   - *Reason:* Generic indigo-to-cyan gradients (`linear-gradient(135deg, var(--accent-primary), var(--accent-cyan))`) used on brand icon and progress bars without identity rationale.
   - *Remediation:* Replace default AI gradients with solid, high-contrast brand tokens from `DESIGN.md`.

8. **R-08 (Button Arrows) [MEDIUM]**
   - *Reason:* Trailing decorative arrows (`→`) are placed on buttons like `Configure Watcher →`, `Configure Encoders & Presets →`, and `View Files →` without directional purpose.
   - *Remediation:* Remove trailing arrows and let concise action verbs define the button CTA.

9. **R-10 (Glassmorphism) [MEDIUM]**
   - *Reason:* Full backdrop blur (`backdrop-filter: blur(12px)`) applied to navbar and modal overlays simultaneously, creating a muddy frosted glass effect.
   - *Remediation:* Use crisp, solid surfaces with refined 1px borders to establish clean elevation.

10. **R-12 (Shadows) & R-13 (Glow) [MEDIUM]**
    - *Reason:* Glowing box-shadows on button hover (`box-shadow: 0 0 12px rgba(...)`) and brand icon produce generic AI float aesthetics.
    - *Remediation:* Remove glow effects; use subtle border highlights and background contrast for hover states.

11. **R-14 (Feature Cards & Metrics Hierarchy) [MEDIUM]**
    - *Reason:* Dashboard presents four identical stat boxes with equal weight, flattening the priority between total storage, savings achieved, and live transcode status.
    - *Remediation:* Redesign the metrics section to emphasize Reclaimed Space and Active Telemetry as hero figures, with supporting metadata subordinate.

12. **R-19 (Animations) [MEDIUM]**
    - *Reason:* Endless looping CSS animation (`animation: pulse 2s infinite`) on running status badges acts as visual noise.
    - *Remediation:* Replace the pulsing badge with a clean, steady status pill and clear tabular progress metrics.

### Tier 3: Quality Locks (Priority: LOW)

13. **R-29 (Color Palette Dispersion) [LOW]**
    - *Reason:* Palette defines 6+ saturated accents (indigo, cyan, emerald, amber, rose, purple) plus inline pink borders, creating visual discord.
    - *Remediation:* Consolidate to the palette in `DESIGN.md`: deep carbon/slate base, Emerald for space saved/efficiency, Cobalt for primary actions/telemetry, and semantic alerts only.

14. **R-05 (Layout & Composition) [LOW]**
    - *Reason:* Section compositions across Dashboard, Queue, and Settings rely on standard box stacks with uniform spacing rather than content-driven rhythm.
    - *Remediation:* Reorganize views to feature real-time active transcode runners prominently and provide dense, scannable data layouts.

15. **R-20 (Visual Identity) [LOW]**
    - *Reason:* Current styling mimics generic AI dark templates rather than reflecting a dedicated media compression powerhouse.
    - *Remediation:* Infuse homelab engineering styling: tabular numbers for bitrates/sizes, crisp borders, and refined status pills.

16. **R-31 (Arbitrary Inline Styles & Reasons) [LOW]**
    - *Reason:* Extensive inline style attributes with ad-hoc colors (`rgba(236, 72, 153, 0.4)`) and arbitrary margins are scattered across page components.
    - *Remediation:* Migrate ad-hoc styles into structured CSS classes in `styles.css` adhering to defined tokens.
